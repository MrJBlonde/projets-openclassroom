# Pipeline DBT — Étude sociodémographique

## Objectif

Analyser l'évolution du profil des étudiants des parcours Data sur 4 ans (2022-2025), pour objectiver les tendances (genre, âge, région) et alimenter les réflexions sur l'accessibilité et l'égalité des chances.

## Démarche

Pipeline de données construit avec DBT (architecture Bronze → Silver → Gold) sur Snowflake, avec 8 tests qualité automatisés et conformité RGPD (pseudonymisation, minimisation des données). Croisement des données d'inscription avec des données INSEE (chômage, population) pour contextualiser les résultats.

## Compétences

Construction de pipeline de données (DBT, Snowflake) · Tests de qualité automatisés · Conformité RGPD · Analyse de tendances temporelles · Croisement de sources de données publiques (INSEE)

**Résultat clé** : profil type identifié (homme, 30-34 ans, francilien, en reconversion), avec 8/8 tests qualité automatisés

**Stack** : DBT Cloud, Snowflake, SQL
